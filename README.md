# IP助手 · 下载

一个 Android 模拟定位工具，支持一键传送、地图选点，以及基于百度地图的城市 / 地点搜索。

## 安装步骤

1. 下载 `IP助手_*.apk`
2. 在手机上点开安装；若提示「未知来源」，请在系统设置中允许浏览器 / 文件管理器安装应用
3. 一加 / ColorOS 等系统可能提示「高风险应用」，这是对非应用商店安装包的常规提示，可选择继续安装
4. 首次启动时授予**定位权限**（模拟定位依赖系统的模拟位置提供者）

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 一键传送 | 填写经纬度，直接定位到目标位置 |
| 去地图选点 | 在地图上点选目标点，自动回填经纬度 |
| 城市 / 地点搜索 | 单输入框 + 城市联想下拉，按键盘「搜索」键检索 |
| 历史记录 | 自动保存最近传送位置，点击可快速回填 |
